## Overview

Neon Horizons is a visionary project aimed at visualizing real-time data for smart city infrastructure. The dashboard uses high-fidelity 3D models to represent city districts and monitor energy consumption, traffic flow, and environmental metrics.

### Key Features

- **Real-time 3D Map**: Interactive city model with live data overlays.
- **Data Visualization**: Complex metrics simplified into intuitive charts and graphs.
- **Dark Mode Optimization**: Designed specifically for low-light control room environments.

### Design Approach

The design aesthetic draws inspiration from cyberpunk culture, utilizing neon accents against dark backgrounds to create high contrast and readability. The interface is designed to be immersive yet functional.
